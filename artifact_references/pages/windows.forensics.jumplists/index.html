      Windows.Forensics.JumpLists

      Parses Windows AutomaticDestinations JumpList files to extract LNK entries with application IDs and target paths.

      The automaticdestinations jumplist is an OLE2 container containing LNK files as individual streams.

      name: Windows.Forensics.JumpLists
description: |
  Parses Windows AutomaticDestinations JumpList files to extract LNK

  The automaticdestinations jumplist is an OLE2 container containing
